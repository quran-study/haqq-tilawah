# Contributing to Haqq Tilawah

Jazakum Allahu khayran for wanting to help. All contributions are welcome: bug reports, corrections, ideas, design and code.

## Ground rules

1. **Never alter the Quran text.** Arabic text and translations must stay exactly as published by their source. If you believe there is an error, open an issue rather than editing the data.
2. **Respect source licences.** Only add data whose terms allow it, keep its copyright notice, and add it to [ACKNOWLEDGEMENTS.md](ACKNOWLEDGEMENTS.md) and the in-app Acknowledgements page.
3. **Keep it open.** By contributing, you agree that your contribution is released under the project's [GNU GPL v3](LICENSE) licence.
4. **Be kind and respectful** in all discussions.

## How to contribute

1. Open an issue describing the bug or idea, so we can discuss it first.
2. Fork the repo and create a branch.
3. Run `pnpm install`, then `pnpm dev` to work locally. Check `pnpm build` and `pnpm lint` pass.
4. Open a pull request linking to the issue.
